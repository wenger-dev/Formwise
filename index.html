How to progress

Build skill before adding load.

Weeks 1–2

Learn the movements

Start with one easy working set per exercise. Keep 3–4 reps in reserve. Practice machine adjustments and controlled reps.

Weeks 3–6

Build consistency

When recovery is good, move toward two sets per exercise. Add reps before adding weight.

Weeks 7–12

Progress gradually

Work toward two or three sets. Increase weight by the smallest increment only after all reps look controlled.

Today's session

Choose a session, log each exercise, and finish when you're done.

Rule #1: No sharp pain, forced reps, or training through unusual weakness. Rest 90–120 seconds between sets. Stop a set while your form is still controlled.

Your data, your control

Export progress

Includes profile, settings, workout sessions, exercise logs, weight entries, and measurements. The JSON can be shared with an AI assistant for a progress review—remove anything you don't want to share.

Import a backup

Import merges no data automatically; it replaces the current local tracker state after confirmation. Export first if you need to preserve your current data.

Local privacy

This prototype uses your browser's local storage. Clearing browser site data may erase your logs. Export a backup regularly. It does not create an online account or sync across devices.
